# CodeAlpha_FitnessTracker

# 🏃 Fitness Tracker App

A simple and interactive Fitness Tracker Web Application developed using HTML, CSS, and JavaScript.

## ✨ Features
- Track daily steps
- Record calories burned
- Monitor workout duration
- Add daily fitness activities
- Select workout types
- View fitness statistics

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
